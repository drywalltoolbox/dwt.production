**Last curated:** 2026-10-30  
**Purpose:** Durable, source-linked context for the DTB Marketing Specialist. This is a curated research corpus, not live system truth and not an assertion of exhaustive market coverage.

## How the agent should use this corpus

Read this index, then consult only the relevant topic file. Treat dated observations as historical evidence. Before making a current claim about a live storefront, product, price, stock, shipping, warranty, service, regulation, search result, or competitor relationship, recheck the responsible first-party or authoritative source and record when it was checked. If a source cannot be reached, say so and retain the value as unknown.

The knowledge base is a governed memory layer: research may suggest updates, but the agent must not silently treat conversation content or its own prior answers as verified fact. New durable entries need source URL, retrieval date, supported claim, confidence/scope, limitations, and conflicts. Proposals should be reviewed before changing curated files or the packaged plugin. Repository/catalog, WooCommerce, Veeqo, analytics, and payment systems retain their existing domain authorities.

## Core operating rules

1. For current domain facts, prefer manufacturer, regulator, repository, or system-of-record sources appropriate to the claim. Attribute retailer/company statements to the publisher.
2. Keep the three standing storefront comparators—Al's Taping Tools, All-Wall, and Wall Tools. Additional candidates require demonstrated relevance; the main panel has a maximum of ten storefronts. Manufacturers and repair providers are tracked separately by role.
3. TapeTech, Columbia Taping Tools, LEVEL5, Drywall Master, Tapepro, Apla-Tech, CanAm, Advance Equipment, and NorthStar are useful initial brand/manufacturer research anchors. Their roles and active status are not equally verified; consult the dated register and recheck unresolved facts.
4. Manufacturer documentation is the starting authority for operating instructions, specifications, maintenance, warranty, schematics, and exact model/part fitment. Similar appearance or third-party interchange claims do not prove compatibility.
5. Contractor discussions are qualitative, self-selected evidence. Do not present them as representative customer research. DTB-specific preferences, repair capacity, sales/demand, conversion, inventory, and live readiness require internal data or direct verification.
6. Preserve dates and observation history; never imply autonomous monitoring or self-training. Tool access and scheduled refreshes must be explicitly configured and tested.

For each proposed update, state the target file, exact claim, evidence URL/document, retrieval date, evidence type, confidence, conflict/gap, and what existing dated statement it supersedes or qualifies.
